Coq grammar ↔ Python coverage audit

The project verifies Guaraní translations against a formal Coq grammar. We audited whether everything the grammar defines is actually reachable in the Python analyzer that feeds it — found 10 gaps, fixed 3, and confirmed the fixes against the project's own gold-standard test suite.
